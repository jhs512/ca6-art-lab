04 / HOW IT WAS MADE

무엇이 다른가요?

A / BASELINE

PixelLab 기본 생성

대상·판타지·카메라를 지정한 짧은 프롬프트. 각 대상을 독립 생성합니다. 별도 스타일 이미지와 공통 팔레트를 지정하지 않습니다.

원화: PixelLab Pro
동작: PixelLab animate_image · 8프레임

B / STYLE LOCK

PixelLab + pixellab 스킬

긴 제작 명세, 공통 32색 팔레트, 조명과 금지 요소를 지정합니다. 모험가 원화를 스타일 기준 이미지로 연결해 나머지 대상을 생성합니다.

원화: PixelLab Pro + 스타일 참조
동작: PixelLab · 공통 기준점·배율 검수

C / PAINTED HYBRID

다른 생성기 + 스프라이트 절차

내장 이미지 생성기로 손그림풍 원화를 새로 만듭니다. generate2dsprite의 크기·기준점 원칙으로 패키징하고, 동작 프레임은 PixelLab으로 생성합니다.

원화: 내장 image_gen · 손그림풍
동작: PixelLab · 같은 동작 조건으로 비교

D / CLAUDE PIXEL RIG

Claude 코드 픽셀 리그

Claude가 코드로 원화를 그리고 파츠 포즈를 바꾼 실제 8프레임입니다. 배경은 codeart2d 타일·레이아웃으로 만들었습니다.

E / CLAUDE SVG RIG

Claude SVG 컷아웃 리그

SVG 원화와 본 리그를 사용한 8프레임입니다. 배경도 SVG 코드 드로잉입니다. 이미지 생성 모델을 사용하지 않았습니다.

F / CLAUDE + PIXELLAB MOTION

Claude 원화 + PixelLab 동작

D 원화를 PixelLab으로 움직였습니다. 배경은 PixelLab 타일셋을 Claude가 조립했습니다.

G / CLAUDE + PIXELLAB REPAINT

Claude 원화 리페인트 + 동작

D 원화를 PixelLab으로 다시 칠하고 동작을 생성했습니다. 배경은 D와 공유하므로 별도로 생성한 배경이 아닙니다.

비교 범위

CodeMonkey의 원본 그림을 복제하지 않고, 원본의 플레이어·추적·도약·밀기·비행·수집·지지 역할을 판타지 대상으로 옮긴 시안입니다. 각 대상의 대표 동작 1개를 비교하며 공격·피격·모든 게임 동작을 완성한 묶음은 아닙니다. C도 애니메이션에는 PixelLab을 사용합니다. 생성 결과의 카메라·체형 변화와 루프 이음새는 그림을 보며 판단해 주세요.
